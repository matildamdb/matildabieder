# Minimal Personal Website

A lightweight, responsive personal website made with plain HTML and CSS. No frameworks, build tools, or paid services required.

## Customize it

1. Open `index.html` in a text editor.
2. Replace `[Your Name]`, the placeholder biography, interests, project descriptions, and `you@example.com`.
3. Replace `yourusername` in the GitHub links with your GitHub username.
4. Remove any sections you do not need. Add a real photo if you want, or keep the typographic placeholder.
5. Save your changes.

## Publish for free with GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io` (replace the words with your username).
3. Upload `index.html` and this `README.md` to the root of the repository.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**. Select `main` and `/ (root)`, then save.
6. Wait a few minutes, then visit `https://YOUR-GITHUB-USERNAME.github.io`.

GitHub Pages is free for public repositories on GitHub Free. Your published site is public, so do not put private information in it. A custom domain is optional and usually costs money; the `github.io` address is free.

## Notes

- This is a static website: no database or server is required.
- The contact link uses email, so it does not need a backend.
- Replace the placeholder links before publishing.
